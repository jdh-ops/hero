# 장비 (3단계 초안)

데이터: `src/data/items.json`(장비 종류), `src/data/affixes.json`(옵션 표). 코드: `src/core/items.ts`, `src/core/build.ts`.

## 슬롯 5개

무기 · 투구 · 갑옷 · 신발 · 반지

## 장비 종류 (기본 옵션)

| 슬롯 | 종류 |
|---|---|
| 무기 | 짧은 검(Lv1) → 넓은 검(Lv5) → 전투 도끼(Lv10) → 대검(Lv16). 기본 옵션: 추가 물리 피해 |
| 투구·갑옷·신발 | 슬롯마다 방어도형(힘) / 회피형(민첩) / 보호막형(지능) × 2단계(Lv1, Lv10) |
| 반지 | 구리(생명력), 은(마나), Lv8부터 루비·사파이어·토파즈(화염·냉기·번개 저항) |

## 등급

| 등급 | 확률 | 추가 옵션 수 |
|---|---|---|
| 일반 | 60% | 0 |
| 마법 | 30% | 1~2 |
| 희귀 | 10% | 3~4 (이름이 무작위로 붙음) |

## 옵션

- 25종. 옵션마다 붙을 수 있는 슬롯과 등장 가중치가 있다.
- 단계 3개: 아이템 레벨 1 / 8 / 16 이상. 아이템 레벨은 처치한 몬스터 레벨.
- 같은 옵션은 한 장비에 한 번만.

## 드랍과 줍기

- 처치 시 20% 확률로 드랍. 가까이 가면 자동으로 주움.
- 빈 슬롯이면 바로 착용, 아니면 가방(40칸).
- 가방(I / Tab / 버튼)을 열면 게임 일시정지. 장비를 누르면 옵션과 착용 시 수치 변화 비교.
- ▲ 표시: 바꿨을 때 수치 변화율 합이 플러스인 장비 (대략적인 판단).

## 저장

- 장착 장비와 가방을 브라우저(localStorage)에 저장. 버전 번호와 저장 시각 포함.
- 죽어도 장비는 유지되고, 위험도(몬스터 레벨)는 1부터 다시.
