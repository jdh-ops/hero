# 스탯과 데미지 공식 (초안)

> 토치라이트: 인피니트(이하 TLI)의 **구조**를 출발점으로 삼고, 덜어낼 건 덜어낸다.
> 이름과 수치는 hero 것으로 새로 정한다. TLI 수치는 비교용 참고값이다.
> ⚠️ TLI 항목 중 출처를 확인한 것은 방어도 공식뿐이다(아래 3.2). 나머지는 기억에 의존한 값이니 실제 게임과 다를 수 있다.

---

## 1. TLI 구조 한눈에 보기

```
기본 피해 (무기 / 스킬 기본값)
  + 추가 피해 ("+X~Y 화염 피해" 같은 고정값)
  × (1 + 증가 합계)          ← "+X% 피해" 끼리는 전부 더함
  × (1 + 추가 증가 1) × (1 + 추가 증가 2) …   ← "추가(Additional)" 는 각각 곱함
  × 치명타 기대값
  × 적 방어 (방어도 / 저항, 관통으로 감소)
  × 받는 피해 증가 (적에게 건 디버프)
```

| 분류 | TLI 내용 |
|---|---|
| 주 능력치 | 힘, 민첩, 지능. 스킬마다 연동 능력치가 있고, 1포인트당 해당 스킬 피해 소폭 증가 |
| 피해 타입 | 물리, 화염, 냉기, 번개, 침식(카오스 계열) |
| 증가 / 추가 | "증가"는 합산, "추가"는 곱연산. 빌드 깊이의 핵심 |
| 치명타 | 치명타 등급(확률), 치명타 피해(기본 +50% 정도) |
| 속도 | 공격 속도, 시전 속도, 이동 속도 |
| 생존 | 생명력, 에너지 보호막, 방어도, 회피, 원소/침식 저항, 막기 |
| 자원 | 마나, 오라 유지를 위한 마나 봉인 |
| 상태이상 | 점화, 동상, 감전, 외상(출혈류), 침식 지속 피해 등 |
| 충전 | 집중 / 민첩 / 강인 같은 축복 충전 |
| 태그 | 공격, 주문, 투사체, 범위, 근접, 지속, 정신집중, 소환 등 |

## 2. 덜어내기 판단

| TLI 요소 | hero 첫 버전 | 이유 |
|---|---|---|
| 힘 / 민첩 / 지능 | **유지 (3종 모두)** | 전사=힘, 마법사=지능, 민첩은 이후 직업(궁수류 등)용으로 미리 넣음 |

| 추가 피해(고정값) | 유지 | 장비 옵션의 기본 재료 |
| 치명타 확률 / 피해 | 유지 | |
| 공격 속도 / 시전 속도 | **"행동 속도" 1개로 합침** | 직업 2개에서는 구분 이득이 적음 |
| 생명력 | 유지 | |
| 에너지 보호막 | **유지 ("보호막"으로 단순화)** | 마법사(지능) 생존 수단 |

## 3. hero 데미지 공식 (초안)

### 3.1 플레이어 → 몬스터

```
1) 기본 피해  = 스킬 기본값 × 스킬 배율 + 장비의 추가 피해(타입별)
2) 증가       = 1 + (모든 "+X% 피해" 합)
                 - 주 능력치 보너스: 연동 능력치 1포인트당 +0.5% (hero 값, 조정 대상)
                 - 타입/태그별 증가: "화염 피해 +", "범위 피해 +" 등 해당하는 것만 합산
3) 추가       = Π (1 + 각 "추가 X%")
4) 치명타     = 치명타면 × 치명타 배율 (기본 1.5)
5) 몬스터 방어 = 물리 → 방어도 감소, 원소 → (1 - 저항)

최종 피해 = 기본 × 증가 × 추가 × 치명타 × 방어
```

기대 DPS(밸런싱 시트용):

```
DPS = 기본 × 증가 × 추가 × (1 + 치명확률 × (치명배율 - 1)) × 방어 × 초당 행동 횟수
```

### 3.2 몬스터 → 플레이어

```
물리: 피해 × (1 - 방어도 감소율)
      방어도 감소율 = 방어도 / (방어도 + K × 몬스터 레벨),  상한 75%
원소(화염·냉기·번개): 피해 × (1 - 저항),  저항 상한 75%
```

받는 순서:

```
1) 회피 판정 → 성공하면 피해 0 (회피는 공격에만 적용, 장판·지속 피해는 못 피함)
2) 방어도 / 저항으로 피해 감소
3) 보호막이 먼저 깎임 → 남은 피해가 생명력을 깎음
```

- **회피 확률** = 회피 / (회피 + K₂ × 몬스터 레벨),  상한 50%
- **보호막 재충전**: 마지막으로 맞은 뒤 2초 지나면 초당 최대치의 20%씩 다시 참 (수치 조정 대상)

- TLI 방어도 공식은 `X / (0.9X + 3000 + 300 × min(적 레벨, 90))`, 상한 80% 형태다. hero는 같은 모양(방어도가 늘수록 효율 감소, 적 레벨이 높을수록 불리)만 따르고 상수 K는 밸런싱할 때 정한다.

### 3.3 치명타

- 치명타 확률: 퍼센트로 바로 표시 (TLI의 "등급 → 확률" 변환 단계는 생략)
- 기본 확률 5%, 기본 배율 150%
- 확률 상한 100%

## 4. 스탯 사전 (첫 버전)

장비 옵션, 특성, 보조 젬은 모두 이 목록에서 고른다.

| 분류 | 스탯 | 표기 예 |
|---|---|---|
| 능력치 | 힘, 민첩, 지능 | +10 힘 |
| 공격 | 추가 물리/화염/냉기/번개 피해 | +5~9 화염 피해 |
| 공격 | 피해 증가 (전체 / 타입별 / 태그별) | +20% 화염 피해 |
| 공격 | 치명타 확률, 치명타 배율 | +3% 치명타 확률 |
| 공격 | 행동 속도 | +8% 행동 속도 |
| 생존 | 최대 생명력, 생명력 재생, 처치 시 생명력 회복 | +40 최대 생명력 |
| 생존 | 방어도, 회피, 최대 보호막 | +120 방어도 |
| 생존 | 화염 / 냉기 / 번개 저항 | +15% 화염 저항 |
| 자원 | 최대 마나, 마나 재생 | +20 최대 마나 |
| 기타 | 이동 속도, 아이템 발견, 줍기 범위 | +10% 이동 속도 |
| 상태이상 | 점화 / 냉각 / 감전 확률, 지속 피해 증가 | +10% 점화 확률 |

능력치의 보조 효과(제안):

- 힘: 1포인트당 최대 생명력 +1
- 민첩: 1포인트당 행동 속도 +0.1%, 회피 +2 (제안)
- 지능: 1포인트당 최대 마나 +1, 최대 보호막 +1 (제안)

## 5. 태그 체계 (첫 버전)

| 종류 | 태그 |
|---|---|
| 형태 | 공격, 주문(주술) |
| 거리 | 근접, 원거리 |
| 전달 | 투사체, 범위 |
| 타입 | 물리, 화염, 냉기, 번개 |
| 시간 | 즉발, 지속(장판·오라 등) |
| 연동 능력치 | 힘, 민첩, 지능 |

- 보조 젬과 "태그별 증가"는 이 태그만 참조한다.
- 전사 예시: `공격 · 근접 · 범위 · 물리 · 힘`
- 마법사 예시: `주문 · 원거리 · 투사체 · 화염 · 지능`
- 한 스킬은 각 종류에서 0~2개 태그를 가짐 (예: 투사체가 터지며 범위 피해 → `투사체 · 범위`)
