# 스킬과 보조 젬 (4단계 초안)

데이터: `src/data/skills.json`, `src/data/supports.json`. 코드: `src/core/skills.ts`.

- 장판(지속) 피해는 회피할 수 없음.
- 조작: 모바일은 오른쪽 아래 버튼 4개(1번이 가장 큼), PC는 1~4 키(Space = 1).

## 보조 젬

- 스킬마다 칸 2개. 한 스킬에 같은 젬은 한 번만. 가진 개수만큼만 여러 스킬에 끼울 수 있음.
- 젬마다 연결 가능한 태그가 있음 (예: 다중 투사체는 투사체 스킬 전용).
- 몬스터 처치 시 5% 확률로 무작위 젬 드랍. 처음에 "집중 타격" 1개 지급.

| 젬 | 조건 | 효과 |
|---|---|---|
| 집중 타격 | 모든 스킬 | 추가 30% 피해, 마나 ×1.3 |
| 근접 숙련 | 근접 | 근접 피해 추가 25% |
| 범위 확대 | 범위 | 반경 ×1.4, 추가 -10% 피해 |
| 다중 투사체 | 투사체 | 투사체 +2, 추가 -25% 피해 |
| 관통 | 투사체 | 관통 +2, 투사체 피해 +20% |
| 잔혹함 | 공격 | 치명타 확률 +5%, 치명타 피해 +30% |
| 신속 | 모든 스킬 | 쿨다운 ×0.75, 마나 ×1.1 |
| 지속 연장 | 지속 | 지속 시간 ×1.6 |
| 화염/냉기/번개 부여 | 모든 스킬 | 물리 기본 피해의 30%를 해당 원소 피해로 추가로 얻음 |

## 공식 변경

- "추가로 얻음(gain as)": 물리 기본 피해(① 단계)의 일정 비율을 다른 타입 기본 피해로 더한다. 더해진 피해는 그 타입의 증가·추가를 따로 받는다(원소 태그 포함).
- 전사 마나: 기본 최대 마나 55(+지능), 초당 재생 5 (스킬 4개를 돌리기 위해 상향).
