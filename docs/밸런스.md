# 밸런스 시트

`npm run balance` 로 다시 만든다 (scripts/balance.ts). 수치를 바꾸면 이 표로 확인.

가정: 전사, 지역 레벨 −2 장비(고급 2옵션 → 희귀 3~4옵션, 열린 티어 중 두 번째), 투사 위주 특성, 스킬 강화 +1/+3/+5/+6,
보조 젬(집중 타격·근접 숙련), 맵마다 평균 1.4판. 받는 피해는 근접 몹 3마리가 붙었을 때.
